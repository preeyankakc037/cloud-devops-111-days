## Key Concepts

Master Node
This is the control part of Kubernetes. It manages the cluster and makes decisions like scheduling and scaling.

Worker Node
These are the machines where applications actually run.

Pod Lifecycle
I learned how pods are created, run, and terminated. It helped me understand what happens internally when I deploy something.

ReplicaSets
They ensure that a specified number of pods are always running. This connects directly with high availability.

Deployments vs Pods
I understood that directly creating pods is not ideal. Deployments manage pods in a much better and controlled way.
