- Maintainable  
- Readable

## What I Did

## Key Best Practices  

### 1. Use Modules  
Break infrastructure into reusable modules instead of repeating code.

### 2. Separate Environments  
Keep different environments isolated:
- dev  
- staging  
- prod  

Each environment should have its own state and configurations.

### 3. Remote State Management  
Store Terraform state remotely (e.g., S3 + DynamoDB) to:
- Enable team collaboration  
- Prevent state conflicts  
- Lock state during changes  

### 4. Use Variables Properly  
Avoid hardcoding values. Use variables for:
- Region  
- Instance types  
- Environment configs  

### 5. Use Outputs  
Expose important information like:
- Instance IP  
- Resource IDs  

### 6. Follow Naming Conventions  
Use consistent and meaningful names for resources and files.

### 7. Keep Code DRY  
Don't repeat yourself — reuse modules and variables.
